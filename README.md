# Anamnese — Guilherme Baima

Site de anamnese estilo synthwave. HTML puro, zero configuração necessária.

## Deploy no Vercel

**Opção mais rápida — drag & drop:**

1. Acesse https://vercel.com (login com GitHub/Google)
1. Arraste a pasta inteira pra dentro do dashboard
1. Pronto. Já vem com domínio tipo `anamnese-baima.vercel.app`

**Ou via CLI:**

```bash
npm i -g vercel
vercel
```

## ⚠️ Primeiro envio

Na primeira vez que alguém preencher a anamnese, o Formspree manda um e-mail
de confirmação pra **guilherme.baima@hotmail.com**. Clique no link de confirmação,
senão os próximos envios ficam pendentes.

## Domínio personalizado (opcional)

Painel Vercel → **Settings → Domains** → adicionar o domínio.

## Arquivos

- `index.html` — site inteiro (HTML + CSS + JS)
- `vercel.json` — config mínima
